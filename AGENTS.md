# Pautas del proyecto

- Haz commits por funcionalidad, con cambios relacionados y completos en cada commit. Usa el formato `tipo: descripción`, con el tipo que corresponda al cambio (`feat`, `fix`, `docs`, `refactor`, `test`, `chore`, etc.).
- Mantén una interfaz limpia y con poco texto, accesible para quienes apenas comienzan a estudiar lenguajes formales.
- Explica las funciones matemáticas con lenguaje claro, preciso e impersonal; evita dirigirte directamente al estudiante.
- Al crear o modificar definiciones, notación, ejemplos y algoritmos, consulta y usa como base el libro de Dexter Kozen sobre lenguajes formales y la [página del profesor Sergio S. Ramírez Rico](https://sites.google.com/site/sergiosramirezrico/eafit/si2002-st0270).
